Лабораторная работа: ООП и SOLID

Тема: Кофейня

Реализация:

ООП:
1. Инкапсуляция. Приватный атрибут __volume, доступ через свойство volume.
2. Наследование. Классы Coffee и Tea наследуют Drink.
3. Полиморфизм. Метод describe() переопределен в наследниках.

SOLID:
1. SRP. Класс Order хранит заказ, класс ReceiptPrinter печатает чек.
2. OCP. Скидка добавляется новым классом HappyHourDiscount, старый код не меняется.
3. LSP. Классы Coffee и Tea подставляются вместо Drink в функции sell_all().

Запуск:
Для запуска программы выполнить в терминале команду:
python coffee_shop.py

Зависимости:
используется только стандартная библиотека Python.
